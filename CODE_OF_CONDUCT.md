# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:
- Showing respect and empathy.
- Giving and receiving constructive feedback.
- Taking responsibility for mistakes and learning from them.

Examples of unacceptable behavior:
- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Any conduct that is inappropriate in a professional setting.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing this Code of Conduct and may take appropriate action in response to unacceptable behavior.

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, and discussions.

## Reporting

Report incidents to the maintainers via repository security contact or private maintainer channel.
