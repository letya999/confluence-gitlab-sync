# Security Policy

## Supported Versions

Security fixes are applied to the latest `trunk` state.

## Reporting a Vulnerability

Do not open public issues for security vulnerabilities.

Report vulnerabilities privately to maintainers with:
- affected component and version/commit
- reproduction steps or PoC
- impact assessment
- suggested mitigation (if available)

Maintainers will acknowledge receipt within 3 business days and provide status updates until resolution.

## Disclosure

After a fix is available, maintainers may publish a coordinated disclosure with remediation notes.
